video2markdown —— 绿色版（解压即用）

【怎么用】
1. 双击 video2markdown.exe
2. 粘贴 YouTube / Bilibili 链接
3. 点「开始生成」

不需要安装 Python，不需要 pip，不需要 ffmpeg（已内置 Python 3.13）。

【第一次运行】
会自动下载 Whisper 模型（小模型约 484MB），需要能连外网（默认走 hf-mirror 镜像）。
下载完之后就可以离线使用。

【生成的文件在哪】
本文件夹下的 output\ 目录。界面上「打开输出目录」按钮可以直接打开。

【想要 GPU 加速（可选，能快 3~5 倍）】
需要 NVIDIA 显卡。在本文件夹打开命令行，执行：
    _internal\python.exe -m pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
（主包没有内置 CUDA 库，因为要多 2GB；不装也能正常用，只是走 CPU）

【文件说明】
video2markdown.exe    图形界面，双击这个
v2m-cli.exe           命令行版，一般不用碰
_internal\            程序本体，不要删也不要改
output\               生成的 Markdown
downloads\            下载的原始音频
audio\                提取出的 wav 和断点存档
models\               下载的 Whisper 模型

【常见问题】
· 界面能开但转写报错 → 点「环境自检」，按提示修复
· 提示连不上 YouTube → 检查代理端口（默认 127.0.0.1:7890）
· Windows 提示"未知发布者" → 点"更多信息 → 仍要运行"（未做代码签名）
· 想省时间：不勾「说话人分离」（它会多花约 1.5 倍时间）
