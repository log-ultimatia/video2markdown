# Buzz vs 本项目 —— 双语视频实测对比

> **测试样本**：`https://www.youtube.com/watch?v=fbpDDiMjoK0`
> 「陶哲軒談 OpenAI 那幾百篇證明…」AI 101 频道，**6:03（363 秒）**
>
> 这支视频**本身就是双语的**：
> - 0~37s 中文旁白
> - 58~330s 英文访谈原声（Terence Tao 本人受访）
> - 330~363s 中文收尾
>
> 所以它是个天然的中英混排测试样本，比我合成的素材更有说服力。

**两边配置都对齐到**：faster-whisper `small`、VAD 开、语言自动、同一台机器、CPU。

> Buzz 的数据来自它自己的数据库
> `%LOCALAPPDATA%\Buzz\Buzz\Buzz.sqlite`（status=completed）
> 本项目的数据来自本次实跑。

## 2. 为什么 Buzz 会丢

Buzz 的做法是 **整段音频只检测一次语言**（从开头 30 秒判断出中文 → 后面全程强制 `zh`）。

Whisper 被强制成中文后，遇到连续英文有两种下场：
1. 把英文"翻译"成中文 → 内容失真
2. **直接跳过不输出** → 就是我看到的 171 秒空白

这正是我之前在你那个中英混排视频上踩到的同一个坑，当时的修法是：
- 分块从 300s 缩到 **60s**
- **每块单独检测语言**、单独挑提示词

| 做法 | 英文词 | 幻觉 |
|---|---|---|
| 整段一次性 | 1 | 13 |
| 逐块 60s | **116** | **0** |

Buzz 的界面里没有暴露 `multilingual` 或逐块检测的开关，所以它没法绕开这个坑。

## 3. 质量细节

| 指标 | Buzz | 本项目 | 谁更好 |
|---|---|---|---|
| 中文字数 | 276 | 183 | Buzz 多（但它只转中文段，本项目把时间花在英文上） |
| **繁体字** | **12** | **0** | 本项目（简体） |
| **中文标点** | **0** | 3 处全角 | 本项目 |
| 英文词 | 4 | **663** | **本项目（差 165 倍）** |
| 段首乱码 | 有（"哈州旗子袆手"） | 有（"这一套奖案"） | 都不好 |

### 两边共同的弱点

**开头的 0~37 秒都转得不好。** 那段是中文旁白 + 背景音乐 + 快语速，Whisper 在这种段落本来就容易出错。

### 本项目待改进：中文标点混用了半角

本项目输出里是 `我们在最初的奖励中,这一套奖案,` —— **半角逗号**，不是全角 `，`。

原因：第 1 块（0-58s）是中英混合，语言检测判成了英文 → 用了英文提示词 → 标点也是英文风格。

**修法**（还没做）：转写后做一次标点规范化 —— 中文语境里的 `,` `?` `!` 换成 `，` `？` `！`。这是个纯文本后处理，改动很小。

## 4. 速度

| | Buzz | 本项目 |
|---|---|---|
| 转写耗时 | **250.0s** | **152.8s** |
| 实时倍率 | 1.45x | **2.4x** |
| 模型 | small | small |
| 词级时间戳 | **开**（额外计算量） | 无 |

**公平性说明**：
- Buzz 开了 **词级时间戳**（word-level timings），这本身会明显拖慢速度。所以"本项目快 1.6 倍"这个数字**不能全算成本项目的优势**。
- 这台机器当时被我多个实验压着，绝对速度都偏慢（正常应该 4~8x 实时）。**两个数字都只适合相对比较。**

### 本次顺手修掉的一个真 bug

本项目原来**每 60 秒一块都重新加载一次模型**（7 块 = 7 次加载）：

| | 耗时 | 实时倍率 |
|---|---|---|
| 修复前 | 289.0s | 1.3x |
| **修复后** | **152.8s** | **2.4x** |

**快了 47%。** 加了模型实例缓存（按 模型/设备/精度 缓存）。24 分钟的视频原来要白白多等一分钟。

另外修了元信息写死 `base` 的问题（实际用 small 也写 base）。

## 6. 建议

| 你的场景 | 用哪个 |
|---|---|
| 单一语言视频（全中文 或 全英文） | **Buzz**（功能全、有界面、能翻译/分说话人） |
| **中英混排 / 多语言视频** | **本项目**（Buzz 会丢段） |
| 要 SRT/VTT 贴回视频 | **Buzz** |
| 要 Markdown 笔记、要断点续跑 | **本项目** |
| 要说话人分离、录音转写 | **Buzz** |

**最实用的组合**：两边都留着 —— 单一语言用 Buzz（功能全），混排语言用本项目（不丢段）。

## 7. 附：复现方式

```
%LOCALAPPDATA%\Buzz\Buzz\Buzz.sqlite
  表 transcription          → 任务记录（耗时、模型、状态）

```

```powershell
cd youtube2md_lab
.venv\Scripts\python.exe pipeline.py "https://www.youtube.com/watch?v=fbpDDiMjoK0" --model small
```
